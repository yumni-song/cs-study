## 1. 자료구조의 기본
자료구조(data structure)는 효율적으로 데이터를 관리하고 수정, 삭제, 탐색, 저장할 수 있는 데이터 집합이다. 어떠한 비즈니스 로직을 처리할 때 그 로직에 가장 효과적인 자료구조를 찾아서 쓰는 것이 중요하며, 이를 위해서는 자료구조를 명확하게 알아야 한다.

이 강의에서는 자료구조를 C++ 기반으로 설명한다. 자료구조를 설명할 때 C++은 매우 좋은 언어이다.

### C++의 기본
```cpp
#include <bits/stdc++.h> // --- (1)
using namespace std;     // --- (2)
string a;                // --- (3)
int main(){
    cin >> a;            // --- (4)
    cout << a << "\n";   // --- (5)
    return 0;            // --- (6)
}
```

1. **헤더 파일**: STL 라이브러리를 import한다. `bits/stdc++.h`는 모든 표준 라이브러리가 포함된 헤더이다.
2. **네임스페이스**: `std`라는 네임스페이스를 사용한다는 뜻이다. `cin`, `cout` 등을 사용할 때 원래는 `std::cin`처럼 네임스페이스를 달아야 하는데, 이를 기본으로 설정한다.
3. **변수 선언**: `<타입> <변수명>` 형태로 선언. 예) `string a = "큰돌"`에서 `a`는 lvalue(다시 사용될 수 있는 변수), `"큰돌"`은 rvalue(한 번 쓰고 다시 사용되지 않는 변수).
4. **입력**: `cin`, `scanf` 등.
5. **출력**: `cout`, `printf` 등.
6. **return 0**: 프로세스가 정상적으로 마무리됨을 뜻함.

> int는 4바이트짜리 정수를 사용할 때 쓰이며, 표현 범위는 -2,147,483,648 ~ 2,147,483,647이다.

## 2. 시간복잡도(Time Complexity)
복잡도는 시간복잡도와 공간복잡도로 나뉜다.

**시간복잡도**란 입력크기에 대해 어떠한 알고리즘이 실행되는 데 걸리는 시간이며, 주요 로직의 반복 횟수를 중점으로 측정된다.

시간이라는 것은 컴퓨터 사양 등 여러 요소에 영향을 받기 때문에, 시간복잡도를 설명할 때는 시간이 아니라 **어떠한 알고리즘이 주어진 입력 크기를 기반으로 어떠한 로직이 몇 번 반복되었는가**를 중점으로 설명한다.

```cpp
for(int i = 0; i < 10; i++){
    for(int j = 0; j < n; j++){
        for(int k = 0; k < n; k++){
            if(true) cout << k << '\n';
        }
    }
}
for(int i = 0; i < n; i++){
    if(true) cout << i << '\n';
}
```

위 코드는 `10n² + n`의 시간복잡도를 가진다.

## 3. 빅오 표기법(Big-O Notation)
### 정의
**빅오 표기법**이란 복잡도에 가장 영향을 많이 끼치는 항의 상수 인자를 빼고 나머지 항을 없애서 복잡도를 나타내는 표기법이다.

예를 들어 `10n² + n`의 시간복잡도는 빅오 표기법으로 `O(n²)`이 된다. n이 1, 3, 9, 12로 증가할 때 n²은 1, 9, 81, 144로 월등히 크게 증가하기 때문이다.

### 빅오 표기법 차트
```
n! > 2^n > n² > nlogn > n > logn > 1
```

### 상수시간 시간복잡도 O(1)
입력 크기와 상관없이 일정한 시간복잡도를 가지는 것을 말한다. O(1)의 시간복잡도를 가지는 예:

- **입력과 출력**: `cin`, `cout`, `scanf`, `printf`
- **사칙연산**: 곱하기, 나누기, 나머지 연산, 빼기 등
- **간단한 비교 if문**
- **배열의 인덱스 참조**: `int b = a[2];`

## 4. 문제로 연습하는 시간복잡도
### Q1
```cpp
for(int i = 0; i < n; i++){
    for(int j = 0; j < i; j++){
        a += i + j;
    }
}
```
**답**: O(n²)

### Q2
```cpp
void solve(int N, int M){
    int a = 1;
    for (int i = 0; i < N; i++) a *= i;
    for (int j = 0; j < M; j++) a *= j;
}
```
**답**: O(N + M)

### Q3
```cpp
int go(int l, int r){
    if(l == r) return a[l];
    int mid = (l + r) / 2;
    int sum = go(l, mid) + go(mid + 1, r);
    return sum;
}
```
**답**: O(n)

### Q4
```cpp
void solve(int N){
    int a = 0, i = N;
    while (i > 0) {
        a += i;
        i /= 2;
    }
}
```
**답**: O(logN)

> 힌트: 로그(log)는 지수 함수의 역함수이다. 어떤 수를 나타내기 위해 고정된 밑을 몇 번 곱하여야 하는지를 나타낸다.

### Q5
```cpp
void solve(int N){
    cnt++;
    if(N == 0) return;
    for(int i = 0; i < 3; i++){
        solve(N - 1);
    }
}
```
**답**: O(3^n)

#### 등비수열의 합 공식
- ① `a(r^n - 1) / (r - 1)` (a: 초항, r: 공비, n: 더하는 것의 개수)
- ② `a / (1 - r)` (a: 초항, r: 공비)

## 5. 시간복잡도가 필요한 이유
시간복잡도는 **효율적인 코드로 개선하는 데 쓰이는 기준**이 된다.

예를 들어 O(n²) 짜리 알고리즘을 O(n)으로 줄인다면 굉장한 성능 향상이라고 할 수 있다. 어떤 버튼을 누르고 화면이 나타나는 데 9초가 걸리는데 시간복잡도를 O(n²)에서 O(n)으로 개선하면 3초가 될 수도 있는 것이다.

## 6. 공간복잡도(Space Complexity)
공간복잡도는 **"입력 크기에 대해 어떠한 알고리즘이 실행되는 데 필요한 메모리 공간의 양"**을 가리킨다. 정적 변수뿐만 아니라 동적으로 재귀적인 함수로 인해 공간을 계속 필요로 할 경우도 포함하며, 배열, 맵, 셋 등 요소들을 담을 공간이면 다 적용된다.

### 예제1
```cpp
int a[10000000];
void f(){
    int b[1004];
}
```
공간복잡도: `1000만 * 4바이트 + 1004 * 4바이트`

### 예제2
```cpp
int a[N];
```
4 * N바이트의 공간이 필요. 빅오 표기법으로는 **O(N)**.

### 문제 풀이에서의 공간복잡도
보통 문제를 풀 때 배열의 범위 등을 잡을 때는 2가지 방법을 기반으로 한다.

#### 1. 최대범위
문제의 최대범위를 기반으로 배열을 미리 만든다. 예) N의 최대범위가 1,000,000이면:
```cpp
int a[1000000];
```

#### 2. 메모리 제한
메모리 제한이 512MB라면 512,000,000 바이트이므로 최대 `int a[128000000]`을 선언할 수 있다.

> 보통 1000만까지는 된다고 생각하고 들어가되 유연하게 문제를 푸는 것이 좋다.

## 7. 정적배열(Array)
배열은 정적배열(array)와 동적배열(vector)로 나뉜다.

**정적배열**은 선언할 때 보통 크기를 설정해서 연산을 진행한다. **연속된 메모리 공간에 위치한 같은 타입의 요소들의 모음**이며, 숫자 인덱스를 기반으로 **랜덤 접근**이 가능하고 **중복을 허용**한다.

### 선언 타입
- **C 스타일**: `int a[10]` (이 강의에서 중심으로 다룸)
- **std 스타일**: `array<int, 10> a;`

### 선언 방법
```cpp
int a[3] = {1, 2, 3};        // 크기 지정
int a2[] = {1, 2, 3, 4};     // 크기 미지정, 자동으로 4가 됨
int a3[10];                  // 크기만 지정
```

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[3] = {1, 2, 3};
int a2[] = {1, 2, 3, 4};
int a3[10];
int main(){
    for(int i = 0; i < 3; i++) cout << a[i] << " ";
    for(int i : a) cout << i << " ";
    for(int i = 0; i < 10; i++) a3[i] = i;
    return 0;
}
```

## 8. 동적배열(Vector)
**vector**는 동적으로 요소를 할당할 수 있는 동적 배열이다. 컴파일 시점에 사용해야 할 요소들의 개수를 모른다면 vector를 써야 한다.

연속된 메모리 공간에 위치한 같은 타입의 요소들의 모음이며, 숫자 인덱스를 기반으로 **랜덤 접근**이 가능하고 **중복을 허용**한다.

### 시간복잡도
- **참조**: O(1)
- **탐색**: O(n)
- **맨 끝에 삽입/삭제**: O(1)
- **맨 끝 제외 삽입/삭제**: O(n)

### 선언
```cpp
vector<타입> 변수명;
```
예) `vector<int> v;`, `set<string> s;`

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> v;
int main(){
    for(int i = 1; i <= 10; i++) v.push_back(i);
    v.pop_back();
    v.erase(v.begin(), v.begin() + 3);
    auto a = find(v.begin(), v.end(), 100);
    if(a == v.end()) cout << "not found" << "\n";
    fill(v.begin(), v.end(), 10);
    v.clear();
    return 0;
}
```

### 메서드
#### push_back()
vector의 뒤에서부터 요소를 추가. `emplace_back()`도 같은 기능을 한다(더 빠르지만 시간차이는 미미).

#### pop_back()
vector의 맨 뒤 요소를 지운다.

#### erase()
```cpp
iterator erase (const_iterator position);
iterator erase (const_iterator first, const_iterator last);
```
한 요소만 지울 때는 `erase(위치)`, [from, to) 구간을 지울 때는 `erase(from, to)`.

> `(`와 `)`은 해당 요소를 포함하지 않는 구간, `[`와 `]`는 해당 요소를 포함한다는 수학적 기호.

#### find(from, to, value)
STL 함수로, [from, to) 구간에서 value를 찾는다. **O(n)**의 시간복잡도를 가진다.

#### clear()
vector의 모든 요소를 지운다.

#### fill(from, to, value)
[from, to) 구간에 value를 초기화한다.

> **범위기반 for루프** (C++11~): `for(int a : v)`는 `for(int i = 0; i < v.size(); i++) int a = v[i];`와 같은 의미.

### vector의 정적 할당
크기를 정해놓고 어떠한 값으로 초기화한 채로 시작할 수도 있다.
```cpp
vector<int> v(5, 100);  // 5개 요소를 100으로 초기화
```

## 9. 메모리와 포인터(Pointer)
### #1 메모리와 주소
```cpp
int i;
```
컴퓨터의 메모리는 메모리 셀의 연속이며 각 셀의 크기는 1바이트이고 고유한 주소가 있다. int 타입(4바이트)의 변수를 저장하기 위해 4바이트의 메모리 영역을 예약한다.

**변수의 메모리 주소**란 변수가 사용하는 메모리 주소의 첫 번째를 가리킨다. 메모리 주소는 16진수로 표기되고, C++에서는 **`&` 연산자(ampersand)**를 통해 변수의 메모리 주소를 얻을 수 있다.

```cpp
#include<bits/stdc++.h>
using namespace std;
int i;
int main(){
    cout << &i << '\n';  // 0x100bbc000
    return 0;
}
```

i에 0을 할당해도 주소는 변하지 않는다.

### #2 포인터
메모리 관리는 언어마다 다르다. Java, Python, JavaScript는 가비지컬렉터가 메모리를 관리하지만, **C, C++**과 같은 하위 레벨 언어는 가비지컬렉터가 없으며 개발자가 직접 메모리를 예약/해제할 수 있고 포인터도 지원한다.

#### 포인터의 개념
**변수의 메모리 주소를 담는 타입**이 포인터이다. 메모리 동적 할당, 데이터를 복사하지 않고 함수 매개변수로 사용, 클래스 및 구조체를 연결할 때 사용된다.

예) 연결리스트의 노드:
```cpp
class Node {
public:
    int data;
    Node* next;
};
```

`<타입> *` 형태로 포인터를 정의한다.
```cpp
int i;
string s = "kundol";
int main(){
    i = 0;
    int * a = &i;
    string * b = &s;
    return 0;
}
```

> C++에서 `*`는 에스터리스크(asterisk operator)라고 불리며, 이항 연산자(곱셈), 포인터 타입 선언, 역참조(dereference)의 3가지 용도로 사용된다.

#### 포인터의 크기
포인터의 크기는 **OS가 32bit라면 4바이트, 64bit라면 8바이트**로 고정된다. 어떠한 타입이든(string, char, int 등) 상관없이 무조건 4바이트 아니면 8바이트로 고정된다. **집 주소의 크기는 집의 크기와 관련이 없다**는 것을 생각하면 된다.

### #3 역참조 연산자
포인터에 `*` 연산자를 통해 **역참조**를 걸어 주소값을 기반으로 값을 끄집어낼 수 있다.

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    string a = "abcda";
    string * b = &a;
    cout << b << "\n";   // 0x6ffdf0 (주소)
    cout << *b << "\n";  // abcda (값)
    return 0;
}
```

### #4 array to pointer decay
배열의 이름을 주소값으로 쓸 수 있는데, 이는 정확히 **array to pointer decay**를 의미한다. 배열이 포인터로 부식(decay)되는 현상으로, 배열의 이름을 `T *` 라는 포인터에 할당하면서 `T[N]`이란 배열의 크기 정보 N이 없어지고 첫 번째 요소의 주소가 바인딩되는 현상이다.

> 참고로 vector는 안 되고 array만 가능하다.

```cpp
int a[3] = {1, 2, 3};
int main(){
    int * c = a;
    cout << c << "\n";      // 0x472010 (a[0]의 주소)
    cout << &a[0] << "\n";  // 0x472010
    cout << c + 1 << "\n";  // 0x472014 (a[1]의 주소)
    cout << &a[1] << "\n";  // 0x472014
    return 0;
}
```

## 10. 연결리스트(Linked List)
연결리스트는 노드로 감싸진 요소를 **인접한 메모리 위치가 아닌 독립적으로 저장**하며, 각 노드는 `next` 또는 `next`, `prev`라는 포인터로 서로 연결된 **선형적인 자료구조**이다.

### 노드란?
노드는 `data`, `next`로 이루어진 구조체이다(싱글연결리스트 기준).
```cpp
class Node {
public:
    int data;
    Node* next;
    Node(){
        data = 0;
        next = NULL;
    }
    Node(int data){
        this->data = data;
        this->next = NULL;
    }
};
```

### 시간복잡도
- **참조**: O(n)
- **탐색**: O(n)
- **삽입/삭제**: O(1)

### 종류
#### 싱글 연결리스트(Singly Linked List)
`next` 포인터밖에 존재하지 않으며 **한 방향으로만** 데이터가 연결된다.

#### 이중 연결리스트(Doubly Linked List)
`prev`, `next` 두 개의 포인터로 **양방향으로** 데이터가 연결된다.

#### 원형 연결리스트(Circular Linked List)
마지막 노드와 첫 번째 노드가 연결되어 **원을 형성**한다. 싱글 또는 이중 연결리스트로 이루어진 2가지 타입이 있다.

### 코드 예제
```cpp
#include <bits/stdc++.h>
using namespace std;
list<int> a;
int main(){
    for(int i = 1; i <= 3; i++) a.push_back(i);
    for(int i = 1; i <= 3; i++) a.push_front(i);
    auto it = a.begin(); it++;
    a.insert(it, 1000);
    it = a.begin(); it++;
    a.erase(it);
    a.pop_front();
    a.pop_back();
    cout << a.front() << " : " << a.back() << '\n';
    a.clear();
    return 0;
}
```

### 메서드
- **push_front(value)**: 리스트의 앞에서부터 value를 넣는다.
- **push_back(value)**: 뒤에서부터 value를 넣는다.
- **insert(idx, value)**: 요소를 idx 번째에 삽입한다.
- **erase(idx)**: idx 번째 요소를 지운다.
- **pop_front()**: 첫 번째 요소를 지운다.
- **pop_back()**: 맨 끝 요소를 지운다.
- **front()**: 맨 앞 요소를 참조한다.
- **back()**: 맨 뒤 요소를 참조한다.
- **clear()**: 모든 요소를 지운다.

## 11. 랜덤 접근과 순차적 접근
**랜덤 접근(Random Access)**은 직접 접근이라고도 하며, **동일한 시간에 배열과 같은 순차적인 데이터가 있을 때 임의의 인덱스에 해당하는 데이터에 접근할 수 있는 기능**이다.

**순차적 접근(Sequential Access)**은 데이터를 저장된 순서대로 검색해야 하는 방식이다.

| 자료구조 | 접근 방식 | n번째 요소 접근 시간복잡도 |
|---------|----------|--------------------------|
| vector, Array | 랜덤 접근 | O(1) |
| 연결리스트, 스택, 큐 | 순차적 접근 | O(n) |
